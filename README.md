# Number System Calculator

A C++ project for converting and working with numbers in different number systems.

## Current Features

- Binary to Decimal conversion
- Conversion from any base (2–36) to Decimal
- Supports digits `0–9` and letters `A–Z`
- Supports both uppercase and lowercase letters
- Validates the input according to the selected base

## Planned Features

- Decimal to any base (2–36)
- Number comparison
- Addition
- Subtraction
- Multiplication
- Division
- Fraction Support

## Technologies

- C++
- Standard C++ Library

## About

This project is being developed from scratch as a learning project.

The goal is to understand number-system conversions, algorithms,
input validation, strings, and C++ programming while gradually
building a functional number-system calculator.
