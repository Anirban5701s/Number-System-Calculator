# Number System Calculator

A C++ project for converting and working with numbers in different number systems.

## Current Features

- Binary to Decimal conversion
- Conversion from any base (2–36) to Decimal for positive and negative integers, including zero 
- Conversion from Decimal to any base (2–36) for positive and negative integers, including zero
- Supports digits `0–9` and letters `A–Z`
- Case-insensitive input for any base to Decimal conversion
- Validates input according to the selected base

## Planned Features

- Number comparison
- Addition
- Subtraction
- Multiplication
- Division
- Fraction support

## Technologies

- C++
- Standard C++ Library

## About

This project is being developed from scratch as a learning project.

The goal is to understand number-system conversions, algorithms,
input validation, strings, and C++ programming while gradually
building a functional number-system calculator.
